## TASK

Write and run a complete automated test suite for the **Word Counter** page of the RealWordCounter Astro website. The page URL in development is **http://localhost:4322/word-counter**.

Use **Playwright** for browser automation testing. Install it if not already installed. Run all tests headlessly. After running, produce a clear pass/fail report.

---

## SETUP INSTRUCTIONS

If Playwright is not already installed in the project, run:

```
npm install --save-dev @playwright/test
npx playwright install chromium
```

Create the test file at:
```
tests/wordcounter.test.js
```

## WHAT TO TEST

Write individual test cases for every single feature listed below. Each test must:
- Have a clear descriptive name
- Assert a specific expected outcome
- Fail with a helpful message if something is wrong

### 1. PAGE LOAD TESTS

- Page loads without any JavaScript console errors
- Page title matches the expected SEO title exactly
- Meta description tag exists and is not empty
- Canonical link tag exists and points to the correct URL
- H1 heading exists and contains the target keyword
- Privacy badge is visible on the page
- Breadcrumb navigation is present and shows correct path
- Page loads in under 3 seconds

### 2. TEXTAREA TESTS

- Textarea is present and visible on the page
- Textarea accepts keyboard input
- Textarea placeholder text is visible when empty
- Typing text into the textarea does not cause any errors
- Pasting a large block of text (500 words) works without lag
- Textarea is visible and usable on a 375px mobile viewport width

### 3. LIVE STATS TESTS

Type the following test text into the textarea and verify each stat updates correctly:

Test text to use:
```
The quick brown fox jumps over the lazy dog. This is a second sentence for testing purposes. And here is a third sentence to ensure accuracy.

This is a second paragraph for testing paragraph counting.
```

Expected results to assert:
- Word count shows exactly 39 words
- Character count shows the correct total including spaces
- Sentence count shows exactly 3 sentences
- Paragraph count shows exactly 2 paragraphs
- Reading time shows a value greater than 0
- Speaking time shows a value greater than 0

Do not modify any source files while running tests. Tests are read-only observation of the existing site.

After the report is generated, if there are failed tests, list them grouped by priority: Critical failures first (page won't load, stats don't update), then Important failures (features broken), then Minor failures (cosmetic or edge cases).
