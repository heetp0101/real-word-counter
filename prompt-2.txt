RealWorldCounter — Phase 2 Build Instructions for Claude Code

CONTEXT
Phase 1 is already built and deployed. It contains the homepage, word counter page, and UPSC word counter page. It also has the complete shared infrastructure: BaseLayout.astro, Navbar.astro, Footer.astro, global.css, components.css, and the sitemap integration.
Do not rebuild or modify anything from Phase 1. Only add new pages. All new pages must reuse the existing BaseLayout, Navbar, Footer, and CSS design system exactly as they are.

WHAT PHASE 2 BUILDS
Six new tool pages. Each page is focused on one specific use case, targets its own keyword cluster, and ranks independently on Google. Together these six pages multiply the website traffic significantly.
The six pages to build are:
	•	/character-counter
	•	/twitter-character-counter
	•	/instagram-caption-checker
	•	/meta-description-checker
	•	/text-case-converter
	•	/readability-checker

SHARED RULES FOR ALL SIX PAGES
Every page must follow these rules without exception.
Each page uses BaseLayout.astro with a unique title, unique meta description, and correct canonical URL.
Each page has WebApplication schema markup as a JSON-LD script tag in the head.
Each page has FAQ schema markup as a separate JSON-LD script tag with at least four questions and answers relevant to that specific tool.
Each page has a breadcrumb navigation showing Home then the tool name.
Each page has a privacy badge visible above the fold saying your text never leaves your browser.
Each page has at least 350 words of real informational content below the tool covering how to use it, who it is for, and relevant tips.
Each page has a More Tools section at the bottom linking to at least four other pages on the site. This internal linking is important for SEO.
Each page has a FAQ section using details and summary HTML accordions matching the FAQ schema above it.
All text analysis must happen live on every keystroke using the input event on the textarea. Nothing is ever sent to a server.
Each page must be fully responsive and work cleanly on a 375px mobile screen.

PAGE 2 — Twitter Character Counter (/twitter-character-counter)
SEO title: Twitter Character Counter — Check Tweet Length Before Posting Free Meta description: Free Twitter and X character counter. See exactly how many of the 280 characters your tweet uses with a live counter and visual tweet preview. No signup needed. Canonical: https://realwordcounter.com/twitter-character-counter
This page is entirely focused on Twitter and X. It is a dedicated focused tool, not a general character counter.
The primary feature is a large Twitter-focused character counter showing the count out of 280 in a visually prominent way. Show it as a circular progress indicator or a large fraction display like 247 / 280 with a color change as the user approaches the limit. Below 240 characters show it in blue. From 240 to 279 show it in amber as a warning. At exactly 280 show it in green. Over 280 show it in red.
Add a live tweet preview card below the counter. This is a styled div that looks like a Twitter post card with a mock avatar, mock username, and the user's actual text displayed inside it. This visual preview is the unique feature of this page that no competitor provides.
Show a character breakdown below the preview: total characters, remaining characters, and if the text contains a URL note that Twitter counts all URLs as 23 characters.
Include a Tips section with five practical Twitter writing tips such as using line breaks for readability, avoiding filler words, and using numbers instead of spelled out words.
There is no word goal tracker, no full stats grid, and no keyword density section on this page. Keep it focused and minimal.
Ad zone: one below the tweet preview card.
FAQ questions: What is the Twitter character limit in 2025. Do spaces count as characters on Twitter. How does Twitter count URLs in tweets. What happens if my tweet is over 280 characters. Does Twitter count emojis as one or two characters.

PAGE 4 — Meta Description Checker (/meta-description-checker)
SEO title: Meta Description Length Checker — SEO Character Counter with Google Preview Meta description: Check your meta description length with a live Google search result preview. Stay within 155 characters. Free SEO tool for bloggers, marketers, and website owners. No signup. Canonical: https://realwordcounter.com/meta-description-checker
This page is a dedicated SEO tool for bloggers and website owners. It is the most valuable page for high-CPC AdSense traffic because the audience is marketers and SEO professionals.
The tool has two separate input fields, not one textarea. The first input is for the Page Title with a 60 character limit. The second input is for the Meta Description with a 155 character limit. Each input has its own live character counter and colored status badge showing whether it is within the recommended limit.
The signature feature of this page is a live Google Search Result Preview card that updates in real time as the user types. This preview card must look as close as possible to an actual Google search result snippet, with a green URL breadcrumb at the top, the blue clickable page title below it, and the grey meta description text below that. Use realistic styling with the correct font sizes and colors to make it feel authentic. When the title is over 60 characters show it truncated with an ellipsis in the preview, just like Google would truncate it. When the description is over 155 characters show it truncated with an ellipsis.
Below the preview show a checklist of SEO best practices with green ticks or red crosses: Title between 50-60 characters, description between 120-155 characters, title contains a keyword (cannot verify this automatically so just show a tip), description ends with a call to action.
Include a Copy button next to each input field that copies just that field's content to clipboard.
There is no textarea, no word goal tracker, no full stats grid, and no file upload on this page. It is entirely focused on the two inputs and the preview.
Ad zone: one below the Google preview card.

PAGE 5 — Text Case Converter (/text-case-converter)
SEO title: Text Case Converter Online Free — UPPERCASE, lowercase, Title Case and More Meta description: Free online text case converter. Convert text to UPPERCASE, lowercase, Title Case, Sentence case, or alternating case instantly. Copy with one click. No signup needed. Canonical: https://realwordcounter.com/text-case-converter
This page is a dedicated text transformation tool. The textarea is the primary element. Below it show eight large clearly labeled transformation buttons in a grid layout: UPPERCASE, lowercase, Title Case, Sentence case, Alternating Case, Remove Extra Spaces, Reverse Text, and Reverse Word Order.
Each button must transform the textarea content immediately when clicked and show a toast notification confirming the transformation was applied.
The transformation logic is as follows. UPPERCASE converts all letters to capitals. lowercase converts all letters to small. Title Case capitalises the first letter of every word. Sentence case capitalises only the first letter of each sentence and lowercases everything else. Alternating Case alternates between uppercase and lowercase for each character. Remove Extra Spaces collapses multiple consecutive spaces and newlines into single spaces and trims the text. Reverse Text reverses the order of every character. Reverse Word Order reverses the sequence of words while keeping each word intact.
Below the buttons add a live character and word count so users can see the stats of their transformed text.
Add a Before and After comparison feature. When the user clicks any transformation button, show a small comparison panel with two columns: the original text in the left column and the transformed result in the right column. Include an Undo button that reverts the textarea to the state before the last transformation. Keep a history of up to 10 transformations so the user can undo multiple steps.
Add a Copy Result button prominently below the textarea that copies the current textarea content to clipboard.
There is no platform limits checker, no goal tracker, and no file upload on this page.
Ad zone: one below the transformation buttons.
FAQ questions: What is Title Case and when should I use it. What is Sentence case. How do I convert text from UPPERCASE to lowercase online. What does alternating case mean. Can I undo a text transformation.

PAGE 6 — Readability Checker (/readability-checker)
SEO title: Readability Score Checker Free — Flesch Reading Ease Calculator Online Meta description: Check your content readability score for free. Flesch Reading Ease calculator with grade level. Get improvement suggestions for blogs, essays, and web content. No signup. Canonical: https://realwordcounter.com/readability-checker
This page is focused entirely on readability analysis. The target audience is bloggers, content writers, teachers, and students who want to know if their writing is easy enough for their audience.
The textarea is the primary input element. All analysis updates live on every keystroke.
The primary feature is a large prominent Readability Score display showing the Flesch Reading Ease score as a number from 0 to 100. Display it in a visually large and clear format. Next to the score show the grade level label (Very Easy through Very Difficult) and a colored badge. Use the same Flesch formula and grade mapping from Phase 1.
Below the score show a Score Gauge that visually represents where the score falls on the scale from 0 to 100. This can be a horizontal bar divided into colored zones or a semicircle gauge. The zones are: 0-29 red (Very Difficult), 30-49 orange (Difficult), 50-59 amber (Fairly Difficult), 60-69 blue (Standard), 70-89 green (Easy), 90-100 bright green (Very Easy).
Show a detailed breakdown below the gauge with these four metrics as individual stat cards: Average Sentence Length in words, Average Word Length in characters, Total Syllables counted, and Syllables Per Word. These help the user understand what is affecting their score.
Show an Improvement Suggestions section that gives specific actionable advice based on the text analysis. If the average sentence length is over 20 words suggest breaking sentences into shorter ones. If the average word length is over 5 characters suggest using simpler vocabulary. If the readability score is below 60 show a warning that the text may be hard for general audiences. Generate these suggestions dynamically based on the actual text, not generic tips.
Show the standard stats below the improvement suggestions: word count, character count, sentence count, paragraph count, reading time, and speaking time.
Show a Keyword Density section identical to Phase 1 with 300ms debounce.
There is no goal tracker, no platform limits checker, and no file upload on this page.
Ad zone: one below the score gauge.
FAQ questions: What is the Flesch Reading Ease score. What readability score should a blog post aim for. What readability score does UPSC expect. How can I improve my readability score. What grade level should general web content target.
